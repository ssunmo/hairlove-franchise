# 머릿결사랑 이미지 클릭 확대

제품 포스터 두 장을 직접 누르면 확대창이 열립니다. 별도의 ‘포스터 크게 보기’ 버튼·문구·돋보기 표시는 없습니다. 기존 살롱의 빛과 그림자 모션, 브랜드 문구와 상담 기능은 유지합니다.

## 기준점과 변경

- 기준 커밋: [`8e81df13284e4439a052208f479c269e626bc47a`](https://github.com/ssunmo/hairlove-franchise/commit/8e81df13284e4439a052208f479c269e626bc47a)
- 작업 브랜치: `codex/restore-image-click-zoom`
- 이미지 클릭·터치로 확대창을 열고 닫기 아이콘·Esc·배경 클릭으로 닫을 수 있습니다. 확대창을 닫으면 원래 이미지로 키보드 포커스가 돌아옵니다.
- 이미지를 감싸는 요소는 키보드·스크린리더로도 사용할 수 있도록 버튼 의미를 갖지만, 별도의 버튼 모양이나 글자는 표시하지 않습니다.
- CSS·JavaScript 버전을 `3.2`로 올려 기존 방문자의 캐시를 갱신합니다.

## 유지되는 모션 동작

- 메인과 제품 영역의 재생·정지 버튼, 관련 스타일 및 사용자 정지 설정 처리 코드를 제거했습니다. 이전 버전에서 저장된 정지 설정이 새 장면을 멈춘 채로 두지 않습니다.
- 메인 사진의 이동, 따뜻한 빛의 흐름, 창틀 그림자, 나뭇잎 그림자를 독립된 CSS 레이어로 구성했습니다. 제목과 상담 버튼은 움직이지 않습니다.
- 제품 포스터는 고정하고 표면 위로 빛이 지나갑니다. 포스터를 읽기 쉽도록 호버·키보드 포커스 중에는 효과가 멈춥니다.
- 화면 밖, 숨겨진 탭, 메뉴·모달 표시 중에는 장면의 모든 효과가 정지합니다. 움직이는 레이어 대신 고정된 장면 경계를 관찰합니다.
- 기기의 `prefers-reduced-motion` 설정을 처음 로드할 때와 실행 중 변경할 때 반영합니다. 모션 감소 시 조명 효과를 숨기고 사진을 고정합니다.
- 그림자의 부드러운 가장자리는 SVG 안에 포함하고, 매 프레임의 CSS 흐림·블렌드 합성을 제거해 렌더링 부하를 줄였습니다.
- 약 132KiB의 기존 고해상도 WebP와 2.5KB의 SVG 그림자를 사용합니다. 운영 페이지에 영상 파일이나 새 프레임워크를 추가하지 않았습니다.

## 검증

Chromium에서 저장소 파일을 브라우저 응답으로 연결하여 검증했습니다. 문의 API 요청은 전부 모의 응답으로 처리했으며 실제 이메일 발송은 0건입니다.

| --- | --- | --- | --- | --- |
| 360px | 통과 | 통과 | 통과 | 통과 |
| 390px | 통과 | 통과 | 통과 | 통과 |

| 1100px | 통과 | 통과 | 통과 | 통과 |
| 1440px | 통과 | 통과 | 통과 | 통과 |

- 네 개의 메인 레이어가 실제로 움직이는 동안 제목 위치가 고정되는지 확인했습니다.
- 이전 정지 설정을 저장한 방문자도 새 모션을 정상적으로 보는지 검증했습니다.
- 실제 스크롤에 따른 화면 밖 정지·재개, 제품 호버·포커스 정지, 기기 모션 감소의 첫 로드·실행 중 전환을 확인했습니다. 숨겨진 탭 처리는 합성 `visibilitychange` 이벤트로 검증했습니다.
- 두 포스터 모두 이미지 클릭·모바일 터치·Enter·Space로 확대됩니다. 별도의 버튼 문구나 돋보기 아이콘은 없습니다. 확대창의 이미지 로딩, Tab 포커스 유지, Esc·닫기·배경 클릭, 닫은 뒤 포커스 복귀와 스크롤 잠금 해제를 확인했습니다.
- 필수값·개인정보 동의·전화번호 자동 형식·모의 전송 성공·서버 오류·네트워크 오류를 확인했습니다.
- JavaScript를 끈 경우에도 본문이 보이고 장면은 정지 상태를 유지합니다.
- [자동 검증 기록](preview/verification.json), JavaScript 구문 검사, `git diff --check`를 통과했습니다. 화면 크기는 브라우저 에뮬레이션으로 검증했습니다.

## 다시 검증하기

홈페이지 자체에는 설치나 빌드가 필요하지 않습니다. Playwright는 검증용 개발 의존성입니다.

```bash
npm ci
npx playwright install chromium
npm test
```

설치된 시스템 Chromium을 사용할 수도 있습니다.

```bash
CHROMIUM_PATH=/usr/bin/chromium npm test
```

영상 기록에는 FFmpeg가 필요합니다.

```bash
CHROMIUM_PATH=/usr/bin/chromium node tests/record-preview.cjs
```

결과는 Git에서 제외된 `test-results/`에 저장됩니다. `TEST_OUTPUT`으로 출력 디렉터리를 선택할 수 있습니다. 검증·영상 생성 스크립트는 모든 문의 요청을 가로채며 실제 이메일을 보내지 않습니다.
